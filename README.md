# GDC Sari-Sari Store - Customer App 🛍️

The companion app for customers to browse, pre-order, and track their purchases.

## 🛠 Features
- **Shop**: Browse available products with real-time stock availability.
- **Pre-Order**: Choose a convenient pickup slot and location.
- **My Orders**: Track the status of your orders (Pending -> Packing -> Ready for Pickup).
- **Refunds**: Easy refund request system for non-perishable goods.
- **Notifications**: Stay informed when your order is ready for pickup or if the store status changes.

## 📱 Tech Stack
- **Framework**: Flutter
- **Database**: Cloud Firestore
- **Auth**: Firebase Authentication (Email/Password)
- **State Management**: Provider
